# Syndee Ann Sevilla — Portfolio

Personal portfolio of **Syndee Ann Sevilla**, Software Engineer · Content Creator · AI Specialist.

Live site: https://syndeeann.github.io/my-portfolio/

**Version 4** (branch `feature/portfolio-v4`): AI-focused. A living neural-network background, decoding headings and an interactive Claude demo; the page turns to horror in the Kwento: Kilabot section and back again. Features AI video creation, Claude, Google Flow, CapCut and Microsoft Fabric, the Kwento: Kilabot AI video pipeline as a case study, and a short software engineering background.

A single static page (`index.html`) with no build step:

- `index.html` — the main portfolio page
- `studio/kwento-kilabot.html` — the Kwento: Kilabot AI Studio workflow page (workflow diagram + YouTube trailers). New workflows get their own page in `studio/`
- `assets/analytics.js` — Google Analytics 4 tracking (set the Measurement ID here); tracking plan and Looker Studio guide in `docs/ANALYTICS.md`
- `syndee.jpg` — profile photo
- `Syndee-Ann-Sevilla-CV.pdf` — downloadable CV

To update the site, edit `index.html` and push to both `master` and `gh-pages`.

The previous React version of this portfolio is saved in the `backup-react-portfolio` branch.
