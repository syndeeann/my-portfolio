About me

Code that feels simple, built with care.

Hi, I'm Syndee.

For more than nine years I've been turning ideas into working software: an e-commerce marketplace and accounting platforms at startups, enterprise Adobe Experience Manager sites at Accenture, and Spring Boot microservices at Myridius, where I'm a Senior Developer today.

Before that, I spent two years in a classroom teaching Java and VB.NET. I still think like a teacher. I like making complicated things feel easy, both for the people who use what I build and for the developers I mentor and review code with.

Lately my curiosity lives where code meets creativity. I work with AI every day, writing prompts that give dependable results, generating video, and pairing with Claude to ship faster. Outside work, I tell stories online as a content creator.
